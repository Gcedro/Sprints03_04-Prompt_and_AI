# Relatório de comparação de modelos

## Objetivo

Comparar pelo menos dois modelos de linguagem utilizando as mesmas perguntas, a mesma base documental e configurações registradas.

## Parâmetros

| Parâmetro            | Configuração inicial |
| -------------------- | -------------------- |
| Temperature          | 0                    |
| Top-p                | 0.9                  |
| Máximo de tokens     | 500                  |
| Top-k de recuperação | 4                    |
| Versão do prompt     | 2.0                  |

## Modelos avaliados

| Critério               | Modelo A    | Modelo B    |
| ---------------------- | ----------- | ----------- |
| Nome e versão          | A preencher | A preencher |
| Provedor               | A preencher | A preencher |
| Faithfulness           | A medir     | A medir     |
| Answer relevancy       | A medir     | A medir     |
| Qualidade das citações | A medir     | A medir     |
| Latência               | A medir     | A medir     |

## Procedimento

Executar os mesmos casos de teste em cada modelo, revisar as respostas e registrar as métricas. Manter a base documental, as perguntas e os parâmetros de recuperação constantes para tornar a comparação mais justa.

## Conclusão

O modelo recomendado será definido após a análise dos resultados reais, considerando fidelidade, relevância, segurança, citações e tempo de resposta.
